# 安行伴移动端 (axb_mobile)

这是安行伴项目的 Flutter 移动端应用包，包含子女端和老人端两个应用。

## 目录结构

```
axb_mobile/
├── anxingban/           # 子女端 App
└── anxingban_user/      # 老人端 App
```

## 快速启动

### 前置要求
- Flutter 3.0+
- Dart SDK
- Android Studio / Xcode (用于模拟器或真机调试)

### 子女端

```bash
cd anxingban
flutter pub get
flutter run
```

### 老人端

```bash
cd anxingban_user
flutter pub get
flutter run
```
