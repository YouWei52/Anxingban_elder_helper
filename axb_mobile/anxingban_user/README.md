# 安行伴 - 子女端移动应用

一个现代化的Flutter移动应用，用于子女管理和关怀老人的出行安全。

## ✨ 功能特性

### 已实现功能

- ✅ **用户认证系统**
  - 注册/登录功能
  - JWT令牌认证
  - 自动登录状态保持
  - 密码强度验证

- ✅ **现代化UI设计**
  - Material Design 3设计语言
  - 渐变色彩方案
  - 流畅的页面切换动画
  - 响应式布局

- ✅ **底部导航**
  - 行程管理
  - 亲子任务
  - 回忆卡片
  - 个人中心

- ✅ **API集成**
  - 完整的RESTful API客户端
  - 自动令牌管理
  - 错误处理机制

### 待实现功能

- 🔲 档案管理（创建、查看、删除老人档案）
- 🔲 行程管理（创建、查看行程和通行码）
- 🔲 任务管理（创建任务、完成任务、反馈）
- 🔲 SOS记录查看
- 🔲 回忆卡片生成和查看

## 📁 项目结构

```
lib/
├── core/                    # 核心功能
│   ├── constants/          # 常量定义
│   ├── theme/              # 主题配置
│   └── utils/              # 工具类
├── data/                    # 数据层
│   ├── models/             # 数据模型
│   ├── repositories/       # 数据仓库
│   └── services/           # 服务层
├── providers/              # 状态管理
├── presentation/           # 表现层
│   ├── screens/           # 页面
│   └── widgets/           # 自定义组件
└── main.dart              # 应用入口
```

## 🚀 快速开始

### 安装依赖

```bash
flutter pub get
```

### 运行应用

```bash
flutter run
```
