# 移动端架构文档

## 技术栈

- **框架**: Flutter 3.13+
- **语言**: Dart
- **UI设计**: Material Design 3
- **状态管理**: StatefulWidget
- **HTTP客户端**: http package
- **本地存储**: SharedPreferences

## 项目结构

```
lib/
├── main.dart                 # 应用入口
├── core/                     # 核心功能
│   ├── theme/               # 主题配置
│   │   └── app_theme.dart
│   └── api/                 # API客户端
│       └── api_client.dart
└── screens/                 # 页面
    ├── welcome/             # 欢迎页
    ├── home/                # 主页
    ├── profile/             # 家庭建档
    ├── trip/                # 创建行程
    ├── sos/                 # 紧急求助
    ├── task/                # 亲子任务
    ├── guide/               # 景点讲解
    └── card/                # 回忆卡片
```

## 设计理念

### 1. 简洁纯色风格

- **主色调**: Material Blue (#2196F3)
- **背景色**: 浅灰 (#F5F5F5)
- **卡片色**: 纯白 (#FFFFFF)
- **圆角**: 8-24px统一

### 2. 大按钮设计

- 主按钮高度: 56px
- 圆角半径: 24px
- 最小点击区域: 48x48dp

### 3. 响应式布局

- 网格布局: 2列
- 自适应间距
- 兼容不同屏幕尺寸

## 核心组件

### 1. API客户端

```dart
class ApiClient {
  static const String baseUrl = 'http://47.237.188.77:8000/api';
  
  Future<dynamic> createProfile(Map<String, dynamic> data) async {
    return await _request('/profiles', method: 'POST', body: data);
  }
}
```

### 2. 主题系统

```dart
class AppTheme {
  static const primaryColor = Color(0xFF2196F3);
  static const bgColor = Color(0xFFF5F5F5);
  
  static ButtonStyle primaryButton() => ElevatedButton.styleFrom(
    minimumSize: Size(double.infinity, 56),
    shape: RoundedRectangleBorder(
```

### 3. 导航系统

使用回调函数实现简单的页面导航：

```dart
void _handleNavigate(String route) {
  setState(() {
    _currentScreen = route;
  });
```


## 状态管理

使用`StatefulWidget`进行简单的状态管理：

```dart
class _ProfileScreenState extends State<ProfileScreen> {
  bool _isLoading = false;
  
  Future<void> _handleSubmit() async {
    setState(() => _isLoading = true);
    try {
      await _apiClient.createProfile(data);
      // 成功处理
    } finally {
      setState(() => _isLoading = false);
    }
  }
}
```

## 错误处理

### 1. API错误

```dart
try {
  final result = await _apiClient.someMethod();
} catch (e) {
  ScaffoldMessenger.of(context).showSnackBar(
    SnackBar(content: Text('操作失败：${e.toString()}')),
  );
}
```
