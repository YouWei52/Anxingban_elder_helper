# 后端架构文档

## 技术栈

- **框架**: FastAPI 0.115.0
- **ORM**: SQLAlchemy 2.0.36
- **数据库**: MySQL 8.0+ (PyMySQL驱动)
- **Web服务器**: Uvicorn 0.30.6
- **配置管理**: Pydantic Settings 2.6.1

## 项目结构

```
app/
├── __init__.py
├── main.py                 # 应用入口，路由注册
├── config.py              # 配置管理
├── database.py            # 数据库连接和会话
├── logger.py              # 日志配置
├── error_codes.py         # 错误码定义
├── modules/               # 业务模块
│   ├── profile/          # 家庭档案
│   │   ├── model/
│   │   ├── controller/
│   │   └── service/
│   ├── trip/             # 行程管理
│   ├── task/             # 亲子任务
│   ├── sos/              # 紧急求助
│   ├── guide/            # 景点讲解
│   └── card/             # 回忆卡片
└── services/             # 共享服务
    ├── sms/
    └── wechat/
```

## 核心设计模式

### 1. 三层架构

- **Controller层**: 处理HTTP请求，参数验证
- **Service层**: 业务逻辑处理
- **Model层**: 数据模型定义

### 2. 依赖注入

使用FastAPI的`Depends`进行数据库会话注入：

```python
@router.post("/api/profiles")
def create_profile(
    profile: ProfileCreate,
    db: Session = Depends(get_db)
):
    return profile_service.create(db, profile)
```

### 3. 配置管理

使用Pydantic Settings从环境变量读取配置，支持`.env`文件。

### 4. 统一错误处理

- 自定义异常类
- 全局异常处理器
- 标准化错误响应格式

### 5. 日志系统

- 分级日志（DEBUG/INFO/WARNING/ERROR）
- 日志文件轮转
- 请求/响应日志
- 错误堆栈追踪

## 数据库设计

### 核心表

1. **profiles** - 家庭档案
2. **trips** - 行程记录
3. **tasks** - 亲子任务
4. **sos_records** - 紧急求助记录
5. **cards** - 回忆卡片

### 关系设计

- Profile 1:N Trip
- Profile 1:N Task
- Profile 1:N SOS
- Trip 1:N Task
- Trip 1:N Card

## API设计规范

### 请求格式

```http
POST /api/profiles HTTP/1.1
Content-Type: application/json

{
  "parent_name": "张三",
  "parent_phone": "13800138000",
  "child_name": "张小明",
  "child_phone": "13900139000"
}
```

### 响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "parent_name": "张三",
    "created_at": "2026-08-25T10:30:00"
  }
}
```

### 错误响应

```json
{
  "code": 404,
  "message": "档案不存在",
  "error": "PROFILE_NOT_FOUND"
}
```

## 安全设计

### 1. 输入验证

使用Pydantic模型进行自动验证。

### 2. SQL注入防护

使用SQLAlchemy ORM，参数化查询。

### 3. CORS配置

生产环境限制允许的域名。

### 4. 敏感信息处理

- 日志中脱敏显示
- 环境变量存储密钥
- 不返回敏感字段

## 性能优化

### 1. 数据库连接池

```python
engine = create_engine(
    DATABASE_URL,
    pool_size=10,
    max_overflow=20,
    pool_pre_ping=True
)
```

### 2. 异步处理

使用后台任务处理耗时操作（短信、webhook）。

### 3. 查询优化

- 使用索引
- 避免N+1查询
- 使用eager loading

## 监控和日志

### 日志级别

- **DEBUG**: 详细调试信息
- **INFO**: 常规操作日志
- **WARNING**: 警告信息
- **ERROR**: 错误信息

### 日志内容

- 请求路径和方法
- 请求参数（脱敏）
- 响应状态码
- 执行时间
- 错误堆栈

### 日志存储

- 文件: `logs/app.log`
- 轮转: 每天或100MB
- 保留: 30天
