## 一、项目概述

**安行伴（Anxingban）**是一个为老年人出行提供安全保障和代际互动的综合平台，包含：

- **后端服务** (axb_back): 基于 FastAPI 的 RESTful API
- **前端应用** (axb_front): 子女端 Web 应用
- **移动端应用** (axb_mobile): 老人端移动应用

### 核心功能模块

1. **双端认证系统** - 子女端和老人端独立账户体系（JWT）
2. **家庭档案管理** - 多成员档案，包含健康信息、兴趣偏好
3. **行程管理** - 创建行程并生成动态通行码（HMAC签名 + 二维码）
4. **紧急求助（SOS）** - 双通道通知（短信 + 企业微信）
5. **代际任务** - 子女创建任务，长辈完成互动
6. **景点讲解** - 基于关键词匹配的重庆景点知识库
7. **数字回忆卡** - 从行程与任务生成回忆摘要

#### 6.2.3 服务层接口抽象

创建 `app/services/agent_client.py` 作为Agent调用的统一接口：

```python
# app/services/agent_client.py
"""Agent客户端 - 调用外部Agent服务的统一接口"""
import httpx
from typing import Dict, Any, Optional
from app.config import get_settings
from app.logger import logger

settings = get_settings()

async def call_agent(
    question: str,
    context: Optional[Dict[str, Any]] = None
) -> Dict[str, Any]:
    """
    调用Agent服务
    
    Args:
        question: 用户问题
        context: 上下文信息（可选），包括：
            - module: 模块名称（guide/task/card/sos）
            - elder_id: 老人ID
            - user_id: 用户ID
            - elder_profile: 老人档案信息
            - current_location: 当前位置
            
    Returns:
        {
            "answer": str,       # Agent返回的答案
            "confidence": float, # 置信度（0-1）
            "metadata": dict     # 其他元数据
        }
    """
    if not settings.agent_enabled:
        raise RuntimeError("Agent功能未启用")
    
    if not settings.agent_base_url:
        raise ValueError("未配置AGENT_BASE_URL")
    
    try:
        async with httpx.AsyncClient(timeout=settings.agent_timeout) as client:
            headers = {}
            if settings.agent_api_key:
                headers["Authorization"] = f"Bearer {settings.agent_api_key}"
            
            payload = {
                "question": question,
                "context": context or {}
            }
            
            response = await client.post(
                f"{settings.agent_base_url}/ask",
                json=payload,
                headers=headers
            )
            response.raise_for_status()
            
            result = response.json()
            logger.info(f"Agent调用成功 - 模块: {context.get('module')}, 耗时: {response.elapsed.total_seconds()}s")
            
            return result
            
    except httpx.TimeoutException:
        logger.error(f"Agent调用超时 - URL: {settings.agent_base_url}")
        raise
    except httpx.HTTPError as e:
        logger.error(f"Agent调用失败 - {str(e)}")
        raise
    except Exception as e:
        logger.error(f"Agent调用异常 - {str(e)}")
        raise

async def check_agent_health() -> bool:
    """检查Agent服务健康状态"""
    if not settings.agent_enabled or not settings.agent_base_url:
        return False
    
    try:
        async with httpx.AsyncClient(timeout=5) as client:
            response = await client.get(f"{settings.agent_base_url}/health")
            return response.status_code == 200
    except:
        return False
```

**为什么需要**：
- 统一Agent调用逻辑，避免在各业务模块重复HTTP请求代码
- 集中处理超时、认证、错误处理
- 未来切换Agent实现时只需修改此文件

```http

    "status": "healthy",

```

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

    answer = your_agent_function(question, context)
    
    return jsonify({
        "answer": answer,
        "confidence": 0.8,
        "metadata": {}
    })

    return jsonify({"status": "healthy"})

    app.run(port=8001)
```
